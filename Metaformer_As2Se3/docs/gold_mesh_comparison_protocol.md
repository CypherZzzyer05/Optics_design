# Au 镀层与 8/4 nm 网格对照协议

本对照是在用户要求提出后新增的研究阶段，尚不能将软件或预检通过写成场增强结论。原先12组训练数据采集已让首组完成并保存，后续批次暂缓；先确定镀层和网格方案，再继续相应数据计划。原项目不改动，开发位于 `codex/gold-mesh-field-comparison` Git worktree。

## 控制变量

固定已完成5→4 nm双谷稳定性检查的同一结构：P=667.2817649、L=167.0369729、H=369.4900803、dX=97.0494522、dY=118.9553182 nm；第一/第三象限−4.96490575°，第二/第四象限41.23316704°。As2Se3 / 350 nm SiO2 / 150 nm Au，法向x偏振、700-1700 nm。

无Au样本把这150 nm体积替换为空气；保留有限厚SiO2、整个计算域、R/T位置、光源、周期边界、PML与金属区域2.5 nm网格。不能直接将历史构造器的 `metal_material=None` 当成公平对照：那会同时把有限基板改为延伸进PML的基板，并移动T监测器。构造后核验原生对象与实际网格，若移除Au改变网格坐标就拒绝受控对照。

## 实算矩阵

1. 无Au、8 nm、3000点全波段预扫，确定其实际谱形及特征波长。
2. 根据已有Au全波段与这次无Au全波段，选择共同的原生计算频率：约1 nm全波段覆盖，重要谱线附近保留0.333 nm密集点。
3. 真空参考8/4 nm，核验电场和磁场归一化。
4. Au8、无Au8、Au4、无Au4，全部重新记录相同探测平面和相同场频率。
5. 每次完成后独立重载FSP，复读R/T/A与E/H，核对导出、源、几何、镀层、网格与边界；FSP校验值必须保持不变。
6. 全矩阵结束、求解器内存释放后，再独立加载四组FSP，读取各自材料表与同一源波段的FDTD拟合。核对共同材料的连续拟合一致性，报告n/k误差及其限制，不把网格稳定性等同于材料准确性。

求解器一次串行运行。原生资源检查先于长算；当前可用内存不足时停止并检查设置，不并行启动第二个FDTD。

## 光谱与场指标

- 光谱分别报告反射R、透射T、总吸收A=1-R-T，以及谱线中心、半突出度线宽与对比度。保留双反射谷和改为其他明显谱形分别描述；总吸收不能直接归因于As2Se3。
- 电场增强定义为 `F_E=|E|^2/|E_inc|^2`，磁场相应定义为 `F_H=|H|^2/|H_inc|^2`。从原生CW源强度计算入射分母，并用真空参考核验。它们是强度增强因子，不是场振幅倍数。
- 记录两个固定XY平面：z=H/2 与 z=H+10 nm。电场覆盖选定频率，磁场记录目标波长和无Au主要反射峰。该采样不能证明三维全空间、全频率的最大场增强。
- 区域平均值按实际网格的面积加权；热点报告面积加权95分位值及最大值。中截面额外统计方柱内部和空气区域，剔除距离柱边缘10 nm以内的节点。单个尖角网格极值不单独作为方案选择依据。
- 相同波长的Au/无Au比值与各自采样共振附近的结果分开报告，防止把共振移位误读为一方完全没有场增强。

用户已确认“影响不大”判据：谷中心位移≤2 nm、反射率绝对变化≤0.03、半突出度宽度相对变化≤10%，核心区域平均场增强与95分位增强相对变化≤10%。已有Au光谱8→4 nm第一谷R变化约0.0410，超过该光谱门槛；它是新增场记录之前的证据，不能代替这次E/H比较。

条件判断只用于当前固定结构。若无Au在光谱特征与场指标上均可替代Au，才移除金层；若8 nm与4 nm在所选方案的核心指标上均一致，才采用8 nm作为该精度等级的网格。否则报告哪些指标改变、量级与适用范围，不放宽判据来获得通过。

## 原始证据和运行

各案例的原始NPZ、配置指纹、资源预检、FSP校验值与原生审计保存于 `data/gold_mesh_comparison/`。`.fsp`保持本机；最终报告、图表和可审计的压缩原始数据提交Git。场强度导出float32，坐标与源归一化float64；原生场复读容差5e-7相对、1e-7绝对，远低于10%比较门槛。

```powershell
python gold_mesh_research.py run --case bare8_preliminary
python continue_gold_mesh_study.py
```
