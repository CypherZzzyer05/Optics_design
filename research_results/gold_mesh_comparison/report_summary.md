# As2Se3 四聚体：Au 镀层及 8/4 nm 网格对照报告

四组同结构对照及两组真空归一化均已完成，原生 FSP 光谱和 E/H 场复读通过。

在当前保存的FDTD材料拟合模型下，当前结构建议：保留 Au。正式精细结果采用 4 nm 网格。

标准：反射谷中心 2 nm、谷底反射率 3 个百分点、半突出度宽度 10%，区域平均及面积加权 P95 场强度增强 10%。

材料限制：保存FSP的Au拟合在目标波长处几乎漏掉材料表中的损耗。以上数值结论限定于当前模型；材料修正后的器件光谱、场增强及取舍尚未验证，本轮不启动此后续仿真。

- Au_vs_bare_8nm: 最大光谱绝对差 R=0.9631、T=0.9711、A=0.9176；目标频率/核心区域最大场平均值相对变化 3000.7%，P95 4046.3%；全部替代判据通过=False。

- Au_vs_bare_4nm: 最大光谱绝对差 R=0.9629、T=0.9709、A=0.9147；目标频率/核心区域最大场平均值相对变化 3034.7%，P95 4032.0%；全部替代判据通过=False。

- Au_8nm_vs_4nm: 最大光谱绝对差 R=0.0524、T=0.0000、A=0.0524；目标频率/核心区域最大场平均值相对变化 4.4%，P95 6.8%；全部替代判据通过=False。

- bare_8nm_vs_4nm: 最大光谱绝对差 R=0.0097、T=0.0307、A=0.0335；目标频率/核心区域最大场平均值相对变化 1.2%，P95 1.9%；全部替代判据通过=False。

无金结构自身反射峰及其共同峰波长处的E/H场网格检查：同时通过=True。未保留Au目标双谷与网格误差分开判断。该辅助范围内可采用8 nm；共同峰波长的E/H平均及P95最大变化为5.1%/6.6%。

局限：固定结构、法向 x 偏振；总吸收不等于 As2Se3 单独吸收；场限于两个 XY 平面和选定频率；数值检查不证明材料拟合或实验精度。报告图表和原始证据见已核验的 Git 版本。
